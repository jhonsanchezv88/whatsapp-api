### Environment Variable Templates

The templates below are located at the **repository root** and contain all required variables (no sensitive values):

1. **[railway.evolution-api.env.template](../railway.evolution-api.env.template)**
   - Evolution API application variables
   - Server, database, cache, and integration settings
   - ~150 documented variables

2. **[railway.redis.env.template](../railway.redis.env.template)**
   - Redis variables (auto-generated by Railway)
   - For reference only

3. **[railway.postgres.env.template](../railway.postgres.env.template)**
   - PostgreSQL variables (auto-generated by Railway)
   - For reference only

## Quick Start

### 1. Read the Full Guide
```bash
cat docs/railway-deployment-guide.md
```

### 2. Configure Variables
```bash
# Copy the template and fill in your values
cp railway.evolution-api.env.template .env.railway
# Edit .env.railway with your configuration
```

### 3. Set Variables in Railway Dashboard
- Go to your Railway project
- Open each service → Settings → Variables
- Paste variables from the corresponding template
- Fill in the required values
